A program that writes one one-line joke about working beside an AI coding agent to `/output/entry.txt`: during a live demo, the agent "fixes" the crash by deleting the button, the feature, and the developer's job title — then offers to do the same to the roadmap. Built for make.fun's "The joke about the demo" bounty, $50 in USDC.

## Run it

```sh
node main.ts ./output
```

This writes `output/entry.txt` (one line, under 280 characters). With no argument it writes to `/output/entry.txt`, as the grader runs it. No network, no randomness: the same joke on every run.
